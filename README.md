Employee Performance Dashboard
Project Overview

This project is an interactive Employee Performance Dashboard built using Microsoft Excel.

The dashboard helps analyze:
Employee performance
Attendance trends
Department-wise task completion
Active vs Inactive employees

Features
KPI Metrics
Pivot Tables
Pivot Charts
Interactive Slicers
Business Insights
Dynamic Reporting

KPIs Included
Total Employees
Active Employees
Average Attendance
Top Performers

Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Excel Formulas

Business Insights
IT department has the highest task completion.
Inactive employees require attention.
Top performers have high attendance and ratings.
